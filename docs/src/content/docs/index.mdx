## Install

<Tabs syncKey="install">
  <TabItem label="macOS / Linux">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/0sec-labs/0security/main/install.sh | bash
    ```

    Supports Apple Silicon macOS and x64 or ARM64 Linux. Installs a checksum-verified binary to `~/.0/bin` and adds it to your `PATH`. Set `INSTALL_DIR` to change the folder.

    Windows is experimental: download `0-windows-x64.exe` from [Releases](https://github.com/0sec-labs/0security/releases/latest).
  </TabItem>
  <TabItem label="Docker">
    ```bash
    docker run --rm -e OPENAI_API_KEY \
      -v "$PWD:/work/source:ro" ghcr.io/0sec-labs/0security:latest \
      scan source /work/source --runtime api --depth quick --cost-ceiling 2
    ```

    The image runs CLI commands, not the browser app. Mount your code and pass your model key. See [Docker](/docker/).
  </TabItem>
  <TabItem label="Source">
    ```bash
    git clone https://github.com/0sec-labs/0security.git && cd 0
    pnpm install --frozen-lockfile && pnpm build
    node packages/cli/dist/index.js web
    ```

    Needs Node.js 24 or newer and pnpm. A source build does not install a global `0` command.
  </TabItem>
</Tabs>

## Run your first scan

<Steps>

1. **Open the app.** Run `0`. The browser app opens at `http://127.0.0.1:48123`. No account is needed.

2. **Connect a model.** Open **Settings → Models** and add a provider key or sign in. See [Models and keys](/models/).

3. **Start a thread.** Press **New thread** and describe the job, for example "Review ./my-app for injection bugs and verify what you find".

4. **Review findings.** Open **Findings**. Each finding links to its evidence. Reproduce it and check a patch with [Verify and fix](/verify-and-fix/).

</Steps>

The **Finish setting up** card in the sidebar tracks steps 2 and 3.

### From the terminal

```bash
export OPENAI_API_KEY=...
0 scan source ./your-repo --runtime api --depth quick --cost-ceiling 2
```

`--cost-ceiling 2` is a soft cap on estimated model spend, in US dollars. See [Costs and budgets](/budgets/). Use `0 scan web` for a live app and `0 scan package` for a published package.

:::caution
Only scan systems you own or are authorized to test. See [Scope and authorization](/scope/).
:::
