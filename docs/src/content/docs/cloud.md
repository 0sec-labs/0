Zero Cloud is retired as a product direction. It is no longer a separate hosted
self-serve offer. Start with the [open-source CLI and browser](/getting-started/),
run it in [CI](/ci/github-action/), or discuss the
[enterprise platform direction](/roadmap/#enterprise-platform) with the team.

The subordinate draft guides preserve historical integration details for
maintainers. Their tokens, endpoints, and enrollment flows do not establish a
current offer or deployed availability. Existing private service code remains
a separate implementation until integration is qualified.
