# Backdrop candidates for the website

`print-sonar.html` is a self-contained canvas 2D page (no build, no network): a slow radar sweep over dotted range rings with a dithered afterglow.
It is the marketing-site hero candidate and is not wired into the app.
Open it directly in a browser; `?theme=dark|light`, `?overlay=1`, `?t=SECONDS` and `?still=1` work.
The in-app backgrounds live in `packages/web/src/ui/backdrops/`.
