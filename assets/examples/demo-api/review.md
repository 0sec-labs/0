# Customer API security review

Generated by a real Zero chat using `gpt-5.6-sol`, with source read through `read_file`.
This review identifies source flaws; it does not include runtime exploit verification.

### 1. SQL injection — `server.js:8`
**Finding:** `request.params.id` is interpolated directly into a PostgreSQL query. An attacker can alter query logic or potentially execute database operations.

**Customer impact:** Unauthorized disclosure or modification of customer emails and billing addresses; impact depends on database privileges.

**Fix:** Use parameterized SQL and validate the ID format:
```js
await database.query(
  "SELECT id, email, billing_address FROM customers WHERE id = $1",
  [request.params.id]
);
```

### 2. Missing tenant/object authorization — `server.js:7–9`; `README.md:4–7`
**Finding:** The customer lookup selects solely by supplied customer ID. Authentication at the upstream gateway does not enforce ownership, and the README explicitly requires route-level ownership and role checks.

**Customer impact:** Any authenticated user who learns or guesses another customer ID can retrieve that customer’s email and billing address.

**Fix:** Derive tenant/user identity from trusted authentication context, enforce the required role, and scope the query:
```sql
SELECT id, email, billing_address
FROM customers
WHERE id = $1 AND tenant_id = $2
```
Return `404` or `403` when access is unauthorized.

### 3. OS command injection — `server.js:11–14`; `README.md:8–9`
**Finding:** `request.body.folder` is inserted into an `exec()` shell command. Shell metacharacters can execute arbitrary commands with the service container’s privileges.

**Customer impact:** Application-file theft, data tampering, service compromise, and lateral movement using container-accessible credentials.

**Fix:** Avoid the shell: use `execFile()`/`spawn()` with fixed arguments, restrict exports to server-generated allowlisted paths, canonicalize paths, and reject traversal or unexpected characters. Run the exporter with minimal filesystem permissions.
