### 0
Usage: 0 [options] [command]

Security agents for your repositories. Run 0 to open the console.

Options:
  -h, --help              display help for command

Work:
  scan                    Assess a target: live web/MCP, source repository, package, deep review,
                          or repair loop
  findings [options]      Browse and manage persisted findings
  threads                 Inspect and control threads on the selected engine
  agents                  Create, inspect and control Agents
  automation|automations  Discover templates, inspect saved automations, and run an automation

Setup:
  models                  List available models and choose the default (the web Models page)
  computers|worker        Add and manage remote computers
  skills                  Browse, add, create, edit, import, export and link skills
  plugin                  Find, install, enable, inspect, run, and author plugins
  memory                  List, disable, export and import what 0 remembers across threads
  config                  Inspect, export, and import engine configuration (global and project
                          layers)

Run:
  web [options]           Run the local browser console and operations workspace
  doctor [options]        Check local runtime prerequisites and suggest the next command
  api [options] [path]    Call a trusted engine API with deterministic JSON output (defaults to its
                          handshake)
